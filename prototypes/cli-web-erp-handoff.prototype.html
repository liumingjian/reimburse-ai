原型问题

从外部安装到 ERP 草稿交接，跨界面节奏是否始终自然且可控？

走通外部安装、个人初始化、材料目录启动、自动整理、最少任务选择、ERP 授权、暂停恢复与草稿交接；观察每一步的状态、控制权和恢复入口是否清楚。

  • 初始化只做一次Codex 前置检查和个人配置留在 CLI，不创建报销任务。
  • 常规运行自动到底run 不插入动作菜单，整理完成才打开 Web。
  • Web 只问材料无法证明的事项目归属由用户选择，整理证据默认折叠。
  • ERP 控制权排他暂停或结果未知时停止写入，核对后才恢复。

    CLI 生命周期安装在 baox 之外；init 检查环境并维护个人配置；run 与 resume 驱动同一个报销任务。
    本地 Web无阻塞性待确认项后才打开，只承载任务选择、ERP 授权、只读状态和聚焦恢复。
    有头 ERP 浏览器只创建并保存草稿；不提交、审核、付款或删除，且任一时刻只由 baox 或用户一方控制。
    恢复从持久事实继续；ERP 阶段先只读对账，写入结果未知时禁止盲目重放。
