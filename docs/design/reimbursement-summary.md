# 报销汇总表

状态：已在集成分支实现，待合并 [PR #465](https://github.com/liumingjian/reimburse-ai/pull/465)。更新于 2026-10-31。

实施规格：[GitHub #459](https://github.com/liumingjian/reimburse-ai/issues/459)，已完成实施。测试边界已由维护者确认。

## 目的与范围

员工除打印发票材料外，还需打印一份报销汇总表。应用使用维护者提供的 `汇总表.xlsx` 自动填表，每个报销任务生成一份独立 Excel，提供预览和下载。跨项目不拆表。

汇总表与现有发票材料打印稿分别生成，不加入现有合并 PDF。术语见 [报销汇总表](../../GLOSSARY.md)。

## 模板

原件位于维护者机器的 `/Users/lmj/Documents/汇总表.xlsx`。原件保持不变，清理后的主表模板已随实现入库。

- 采用 `报销单 (2)` 主表，保留财务表单版式、费用栏目及 A4 纵向、水平居中的打印设置。
- 清除主表历史填写值，移除包含人员名单的 `Sheet2`，不把示例数据当作默认值。
- 公司抬头沿用模板。
- 单据编号和出差单编号可手填，留空也能生成，不等待 ERP 分配编号。
- 表头报销日期默认首次生成当天，允许员工修改。重复下载保留已选日期。
- `I3:K3` 原为存放日期的合并区域，采用报销日期含义。报销日期与出差单编号是独立字段。
- 保留金额合计自动计算能力，核验大小写金额对角分的正确表达。原件大写金额公式末尾固定拼接“元整”，不能仅保留公式文本就视为计算正确。

## 金额与张数

金额直接取明细中确认的金额，按下表对应关系汇总。不是重新读取票面金额后另算报销金额。各栏目金额之和须等于本次确认的报销总额。

| 费用类别 | 模板栏目 |
| --- | --- |
| 住宿 | 住宿费 |
| 本地市内交通 | 出租车费、地铁、公汽：市内 |
| 外地市内交通 | 出租车费、地铁、公汽：外地 |
| 长途交通 | 飞机、火车、长途汽车票 |
| 招待费 | 餐费：招待 |

其他费用栏目留空。

单据张数只统计本次报销中去重后的主要报销凭证。参考材料、文件页数和拆分明细均不增加张数。

同一张主要报销凭证跨类别时，金额分别计入明细对应的类别，张数只计一次。员工选择这张凭证的张数归入哪个类别，不因此改变费用明细的分类或金额。

## 住宿天数

每笔住宿按离店日期减入住日期计算天数，再逐笔相加。同日入住、离店时由员工确认天数，不直接计为零。

计算只用于汇总表，不反向改写票面日期或材料中的晚数。既有材料校验仍适用，离店早于入住等无效日期不作为合法住宿参与计算。

## 员工信息与个人模板

员工姓名和部门取自 ERP“个人信息”。存在多条任职记录时，部门以页面最后一条任职记录为准，不默认取第一条，也不让员工逐次选择。

每个应用账号持久化自己的个人模板资料，并绑定 ERP 账号和账套。首次获取后复用，更换 ERP 账号或账套后重新获取姓名和部门，不使用旧身份的资料生成新汇总表。

在保存、验证 ERP 账号时同步获取个人信息。已有账号在首次生成汇总表前补取。获取失败时提示重试，取得资料后再生成汇总表。后续可使用保存的资料，无须每次登录 ERP。

个人信息读取不等于发票导入、费用明细写入或暂存授权。

## 生成与更新

- 整单明细确认后，使用同一份确认数据生成汇总表，供员工预览并下载 Excel。
- 费用明细变更后，原确认和汇总表失效，须重新确认并生成。
- 修改日期、姓名等打印信息只更新汇总表，不使费用明细确认失效。
- 再次下载保留员工选择的报销日期。

## 验收条件

- 同一任务跨多个项目仍生成一份汇总表，五类费用进入对应栏目，金额合计与确认总额按分一致。
- 一张住宿发票附多份参考材料仍只计一张，一张发票拆多条明细仍只计一张；跨类别时完成张数归属后不重复计数。
- 多笔正常住宿的日期差正确累计，同日住宿等待员工确认天数，票面日期保持原值。
- 多条任职记录取最后一条的部门。个人模板按应用账号隔离，更换 ERP 账号或账套后更新员工信息。
- 员工资料首次读取失败时不能带旧资料或空资料生成。取得资料后重复生成不要求重复登录。
- 预览与下载的 Excel 内容一致，金额包含角分时大小写均正确；Excel 中金额输入变化后合计仍可自动计算。
- Excel 可按模板版式打印，原件示例姓名、编号、金额和人员名单不出现在输出中。
- 修改费用明细后不能继续使用旧汇总表，修改报销日期后重复下载仍保留该日期。

## 实施说明

- 姓名、部门从 ERP 个人信息读取，随应用账号的 ERP 凭据保存；生成时写入汇总表，允许员工修正打印信息。
- 同日住宿天数和跨类别张数归属按整单确认版本保存；重新确认后需重新补充，不改材料事实。
- 本次 Excel 模板方案替代原先暂缓明细汇总表和预设 Word 表单的取舍。
