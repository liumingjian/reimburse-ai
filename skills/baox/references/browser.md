# 浏览器

## 正常使用

ERP 和本地交互页面通过系统默认浏览器打开。执行内核发出的命令，由系统选择浏览器；不替用户改变默认设置，也不启动专用 Chrome。

打开页面不等于能读取 ERP。当前登录身份与项目核验仍由内核只读适配完成。内核报告权限或浏览器能力缺失时，原样说明具体缺项，让用户处理后重试；不沿用旧登录记录，不把用户口述身份记为当前 ERP 探测结果。

完成条件：本地页面已在默认浏览器打开；需要 ERP 读取的步骤得到当前身份下的实际结果。用户完成本地交互后以服务器接受的结果继续，普通浏览器的标签可由用户自行关闭。

## 自动化 QA

只有当前任务明确选择 ego 自动化 QA 时，才在执行环境设置 `BAOX_BROWSER=ego`，并提供已确认的 `BAOX_EGO_TASK_SPACE`。单独存在 task space 配置不改变正式浏览器选择。QA 执行时保持同一任务空间，按 ego-browser 的控制权协议操作。

完成条件：明确选择的 QA 适配可用，结果标记为 Agent QA；不把 QA 工具要求写成普通用户的安装前提。
